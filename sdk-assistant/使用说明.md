# Genisom SDK Skill 使用说明

这个 Skill 帮你查找官方 SDK 接口、核对版本、编写 C++／CMake 工程和排查编译问题。Genisom L1 系列和 Genisom M1 支持中英文资料。Genisom L2 使用中文资料，也可以用英文提问。Skill 默认通过索引查阅文档，装好后即可使用，无需配置 MCP。

## 在 Codex 中安装

在机器人开发项目根目录下创建 `.agents/skills/`，把这里的 [`skills/genisom-sdk/`](skills/genisom-sdk/) 整个目录复制进去。安装后应能看到 `.agents/skills/genisom-sdk/SKILL.md` 和旁边的 `references/`。如果希望多个项目共用，可以复制到个人目录 `~/.agents/skills/`。打开目标项目的新会话，输入 `$genisom-sdk` 选择 Skill。 [Codex 安装说明](https://developers.openai.com/api/reference/cli)

## 第一次使用

打开已有的 SDK 工程，或在提问时提供 SDK 所在目录。给出机器人型号、目标系统和处理器架构。如果要确认兼容性，补充 SDK 版本及机器人系统版本。可以从下面的示例开始，把版本换成你实际使用的版本。

> $genisom-sdk 我用 Genisom M1，机器人系统为 v0.3.4，SDK 为 v0.2.3，目标是 Ubuntu ARM64。请参考当前项目里的 SDK 头文件，创建一个 C++／CMake 示例，连接后只读取设备型号和序列号。只编译，不运行连接真机的程序。请给出参考章节和编译结果。

还可以这样提问：

- **查接口**：`$genisom-sdk` 我用 Genisom L1-W。请找出心跳和故障信息章节，解释各自能确认什么。
- **查版本**：`$genisom-sdk` Genisom M1 系统 v0.3.0 搭配 SDK v0.2.1 时能否调用 `UpdateCameraBitrate()`？请引用兼容性说明。
- **查编译问题**：`$genisom-sdk` Genisom L2 的工程在 ARM64 上链接失败。请根据构建日志和本地 SDK 文件定位原因，只在本地检查和编译。

查看回复里引用的型号、SDK 版本和来源。编译验证需要目标架构对应的 SDK 库及工具链。真机运行需要开发者根据产品手册单独验证。

## 使用本地或离线文档

如果已有文档仓库，可以直接把本地路径告诉 Codex。需要随 Skill 带走 Markdown 时，从文档仓库根目录使用 Python 3 导出。把下面的路径替换为已复制到机器人项目的 Skill 目录。目标 `markdown/` 需要是新目录。

```sh
python3 sdk-assistant/build_index.py \
  --export "/path/to/robot-project/.agents/skills/genisom-sdk/references/markdown"
```

导出包含对应文档目录的 Markdown 和该快照的 `llms.txt`，保留文档间的相对路径。图片和下载附件请在索引链接指向的文档站查看。离线副本取自运行命令时的本地文件，可能包含尚未发布的内容。

## 维护索引

SDK 章节更新后，从文档仓库根目录运行下面的命令。索引链接默认指向 Genisom AI 的文档站。如需为另一套部署生成索引，可用 `--site` 指定包含站点路径前缀的完整地址，并在检查时使用相同参数。索引末尾的 SHA-256 用于识别已索引的 Markdown 内容快照。

```sh
python3 sdk-assistant/build_index.py
python3 sdk-assistant/build_index.py --check
```
