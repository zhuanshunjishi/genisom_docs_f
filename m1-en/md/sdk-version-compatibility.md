## SDK Compatibility Notes

For Genisom M1 system versions earlier than those in the version matrix, see the SDK recommendations below.

| Genisom M1 System Version | Recommended SDK |
| --- | --- |
| `v0.0.5` to `v0.1.0-B` | `v0.0.3` |
| `v0.1.0-C` up to, but excluding, `v0.1.9` | `v0.1.1` |

Genisom M1 system `v0.3.1` also supports SDK `v0.2.2`. The Robot SDK guide recommends `v0.2.2` for new projects on this system version. See [Robot SDK compatibility](https://github.com/zsibot/genisom_robot_sdk/blob/main/README.md#sdk-and-robot-system-compatibility).

With Genisom M1 system `v0.3.0` and SDK `v0.2.1`, basic control and status reads work. The protocol definition for `UpdateCameraBitrate()` is incompatible with this combination. For the camera bitrate API, use SDK `v0.2.0` or upgrade the robot system to `v0.3.1` and select a compatible SDK.
