# M1 system and SDK version compatibility

[Return Document Overview](../index.md) | [M1 SDK Quick start](./04-sdk-quickstart.md)

First confirm the version of the robotic system, then choose SDK according to the following table. The full description is [Official compatibility table](https://github.com/zsibot/genisom_robot_sdk/blob/main/README_zh.md#sdk-与机器人系统版本兼容性).

| M1 System version | Recommended SDK |
| --- | --- |
| `v0.0.5` ～ `v0.1.0-B` | `v0.0.3` |
| `v0.1.0-C` ～ `v0.2.4` | `v0.1.1` |
| `v0.3.0` | `v0.2.0` |
| `v0.3.1` ～ `v0.3.3` | `v0.2.2` |
| `v0.3.4` | `v0.2.3` |

M1 System `v0.3.0` Matches SDK `v0.2.1`, basic controls and state readable, `UpdateCameraBitrate()`. When using the camera number ratio interface, you can use the above table instead. SDK `v0.2.0`, or will M1 System Upgrade to `v0.3.1` After Select Compatibility SDK.
