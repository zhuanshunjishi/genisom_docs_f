## SDK 兼容说明

早于上表的 M1 系统版本可参考以下 SDK 推荐版本。

| M1 系统版本 | 推荐 SDK |
| --- | --- |
| `v0.0.5` ～ `v0.1.0-B` | `v0.0.3` |
| `v0.1.0-C` 起，早于 `v0.1.9` | `v0.1.1` |

M1 系统 `v0.3.1` 也兼容 SDK `v0.2.2`。Robot SDK 指南建议新项目在该系统版本上使用 `v0.2.2`。详见 [Robot SDK 兼容性说明](https://github.com/zsibot/genisom_robot_sdk/blob/main/README_zh.md#sdk-与机器人系统版本兼容性)。

M1 系统 `v0.3.0` 搭配 SDK `v0.2.1` 时，基础控制和状态读取可用，`UpdateCameraBitrate()` 的协议定义不兼容。使用相机码率接口时，请改用 SDK `v0.2.0`，或将 M1 系统升级至 `v0.3.1` 后选择兼容 SDK。
